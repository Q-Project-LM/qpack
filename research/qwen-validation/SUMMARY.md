# Qwen2.5-0.5B-Instruct: q4m allocation comparison

Model source: Qwen/Qwen2.5-0.5B-Instruct, revision 7ae557604adf67be50417f59c2c2f167def9a775; see source.json and download log. Original f32 container generated by convert_np. Both variants: q4m, GPTQ, act-order, same calibration text and 2044 tokens, 8 threads; commands.json has exact commands. Each PPL measurement uses 1020 tokens with context 256, 4 chunks; lower is better. The calibration and evaluation texts are distinct, but Wikipedia-derived samples can share subject matter.

| Dataset | Default q4m | q4m-last-half |
|---|---:|---:|
| wiki RU | 10.4777 | 10.5100 |
| wiki EN | 15.5078 | 15.5584 |
| extended RU | 20.0007 | 20.1986 |
| extended EN | 15.3373 | 15.3154 |

Sizes: 369546048 vs 369546112 bytes. Last-half is worse on 3/4 sets and better on 1/4, so retain default q4m for Qwen; the optional last-half mode is an experimental, model-specific result, not a universal improvement. Small test sets and one model preclude broad generalization. Individual logs and results.json contain measurements.

The convert_np input has no selftest: quantized models report 0/0, which is no verification. Separately converted the same Hugging Face model with convert_llama --quant none; its f32 selftest against Transformers passed 5/5, max absolute logit error 7.07e-3 (reference-convert.log and reference-selftest.log). This validates the runtime on this reference input, not quantized outputs against independent logits.

## Follow-up: longer calibration

Same f32 input, q4m GPTQ act-order, text and evaluation; request 4096 calibration tokens instead of 2044. The program reports 4088 actual tokens because it processes complete blocks. File sizes are identical at 369546048 bytes. Quantization took 210.9 seconds versus 179.5 seconds in this pair (single runs, not a robust timing benchmark).

Selection and first four tests use short, partially related texts, so more datasets and architectures are needed. Quantized files still have no selftest cases. This is a calibration setting improvement on this model, not an algorithm or default change. See ../qwen-calib-4096/ and ../qwen-fiction-holdout/ for commands and logs.
