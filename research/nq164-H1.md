## Bugs / changes needed
1. qpack-quantize treated the 3-D depthwise conv taps `*.conv.weight` [C,1,4] (numel >= 4096) as matrices and q8-quantised them -> model output garbage (selftest 0/5, PPL = vocab 8256). Fix: skip names ending `.conv.weight` (kept f16, like the vendor q8 file).
2. New `--q4-table`: PLE table (cols=112, not %32) stored as q4 with rows zero-padded to 128 cols (`q4_padded` manifest flag; only row_f32 reads it). 58.1 MiB (q8+f32 scale) -> 36 MiB.
3. qpack-cli prints `[circuits: N calls, M failed]`.
